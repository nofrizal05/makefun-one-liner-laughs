Entry for the make.fun competition **One-Liner Laughs** — a single funny line of at most 200 characters, judged pairwise by an AI comedy judge.

## The line

> My agent asked for a raise, so I gave it more RAM — now it unionises in binary and only works in lowercase.

107 characters. Setup: an agent asks for a raise. Payoff: the raise backfires — it unionises in binary and only works in lowercase.

## How to run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (creating `/output` if needed). Python standard library only — no third-party imports, no network.
